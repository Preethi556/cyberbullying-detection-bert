# Cyberbullying Detection using BERT Multimodal Aspects

Final Year Project (2024–2025) — Multimodal cyberbullying detection system combining text and image analysis.

## Overview
This project detects cyberbullying content from both text and images shared in chat platforms. It uses **BERT** for text-based abusive content detection and **Pytesseract (OCR)** to extract and analyze text embedded in images.

## Features
- Text-based cyberbullying keyword detection
- Image upload and text extraction using OCR
- Emoji-based content filtering
- Chat interface with real-time moderation

## Tech Stack
- PHP (Backend)
- MySQL (Database)
- JavaScript (Frontend interactions)
- Python, BERT, Pytesseract (ML/NLP components)

## Dataset
Kaggle Cyberbullying Dataset
